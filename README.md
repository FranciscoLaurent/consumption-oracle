# 「消费预言机」深度开发版 v1(P0 完整实现)

> **一句话**:你的下一次冲动消费,让朋友来预言——7 天后开奖,打脸或真香,都算数。
> **在线体验(GitHub Pages)**:<https://franciscolaurent.github.io/consumption-oracle/>
> 单文件、零依赖、双击即开的 390×844 移动端可点击原型(延续 saving-zoo 仓库设计语言)。
> **定位**:决策报告首选方案的 P0 落地实现 =「冲动急救站(入口模块)× 消费预言机(传播引擎)× 预言家档案(留存资产)」三段式。
> 决策依据:六候选七维评分首选(3.73/5),详见会话决策报告;仓库 `saving-zoo` 的红队方法论全程作为设计约束。

---

## 一、打开方式

1. 双击 `index.html`(Chrome / Edge,`file://` 直接可用;无服务器、无外部请求)。
2. 桌面端:深色网格背景 + 居中手机模型;窄屏(≤480px)自动铺满。
3. **数据持久化**:本机 `localStorage`(key `oracle_prophet_v1`),刷新/重启不丢;急救战绩、预言、开奖结果、换算设置均保留。档案页可「清空演示样本」或重置。
4. 调试接口:`window.__oracle = { state, go, errors, exportCard }`;`window.__errors` 收集运行时错误。

## 四、爆款条件对照表(报告第四节逐条落地)

| 爆款条件(源自钱包请等等/SBTI 拆解) | 本实现的回答 |
|---|---|
| 寄生既有认知,一句话讲清 | 「让朋友预言你 7 天后会不会后悔」= 朋友间"你等着后悔吧"打赌文化,零学习成本 |
| 10 秒可截图的传播物 | 预言卡/打脸卡/守住了卡/预言家卡 四张票根风卡,全部支持一键导出 PNG |

| 悬念带来二次传播 | 7 天倒计时 = 预约的爽点;开奖时刻是第二个传播高峰(开奖卡一键发回原群) |
| 3 步内爽点 | 打开 → 按大按钮/发起 → 60 秒出卡,零注册 |
| 参与即传播 | 好友 3 秒一票是玩法本身;先投票才解锁神预言墙(防从众+解锁期待,学自钱包请等等) |
| 用户自产内容有模具 | 理由/毒舌全 chips 模板化+40 字自定义,平台不养内容 |
| 身份型拉新+内容型留存 | 预言家档案(身份)+ 每一场真实预言/开奖(内容);急救站提供高频入口 |
| 分享零奖励、零诱导 | 全部分享入口明示"分享不带奖励";卡片无二维码;无邀请解锁 |
| 分歧/对立可讨论 | 会后悔 vs 不会 vs 根本不会买;自押 vs 朋友;最懂你的人排行(下版) |

**同质化雷区规避对照**(报告列出的 8 条):不做审批/投票劝退(✓机制不同)、不做省钱皮人格测试(✓)、无养成打卡(✓以真实开奖日历替代)、无假社会证明(✓跑马灯标注"演示样本,上线首日为真实计数")、无羞耻标签(✓诚实卡不羞辱/无星级)、无诱导分享与二维码(✓)、零广场 UGC(✓chips+短文本+敏感词替换,个人主体可做)、广告不接电商借贷(✓本原型无任何广告位,变现见报告)。

## 六、自测记录(实机走查,浏览器 CDP)

**环境**:ZCode 内置浏览器,视口 460×900(http://127.0.0.1:8123 静态服务,`file://` 等价);全流程真实点击驱动,关键屏截图确认。

**已验证路径**:
1. ✅ 急救全流程:呼吸(6→1 自动推进)→ ¥38 清醒换算(0.8 小时/2.5 杯/0.4 天+文案)→ 出口③「让朋友预言」预填 → 生成预言卡(¥38,开奖时间 =+7 天)
2. ✅ 预言卡:三票区/条形码/群发话术;canvas 导出 PNG(257KB)
3. ✅ 好友视角:毒舌 chip+投票 → 票数 +1 → 神预言墙解锁;一键模拟 3 位好友(共 4 票)
4. ✅ 详情:倒计时实时(剩 6 天 23 时)→ 快进 → 「已到开奖时间」→ 去揭晓
5. ✅ 打脸卡:买了+后悔 → 预言家命中 1/4(判定逐票核验正确)+ 自押正确 + 应验印章 + 导出
6. ✅ 守住了卡:没买 → 命中 1/2 + 「你押错了·最不懂的是自己」+ 清醒印章
7. ✅ 预言家档案:40% 圆环、「民间观察员」、预言 3 场/投票 10 次/命中 4 次/押中自己 2/3、最懂你的人:老赵(1/2)——与三场数据人工核验一致
8. ✅ 急救「按住了」:¥59 入账(saved 129+59=188)、周记录绿点、劫后余生卡+导出(226KB)
9. ✅ 持久化:reload 后预言/战绩/设置全部保留
10. ✅ 质量门:三个 Tab `scrollWidth==clientWidth`(无横向溢出);`window.__errors=[]`;代码零外链(无 CDN/字体/图片/请求)

**实机走查中发现并修复的 bug(2 个)**:
1. **导出弹窗关不掉**(阻断级):事件委托器把所有 handler 统一调用为 `fn(v, closer)`,而 `mClose(e)` 期望原始事件;`.modal` 无 `data-v` → `getAttribute` 返回 null → `null.target` TypeError。修复:mClose 特判接收原始事件+空值防御。
2. **劫后余生卡白屏**(阻断级):`aidHold/aidBought` 回调引用了不存在的 `renderAidCard`(渲染器注册在 `RENDER['s-aidcard']`)。修复:回调统一改为 `rerender()`;顺带为所有返回型导航补上重渲染(8 处)。

**测试环境说明**:后台标签页对 180ms 过渡定时器/动画有节流(仓库 demo 同现象),前台真实使用无影响;自动化坐标点击在视口底缘(tabbar)不可达,属工具限制。

## 七、已知问题 / 下版计划(P1)

1. **好友投票为单机模拟**:正式版由分享链接直达投票页(小程序卡片 + openid);「好友视角试投/一键模拟」仅演示闭环。
2. **群预言模式**未做:预言卡发群多人投票、群准确率榜(不需要群主开园,任何人发卡即可)。
3. **开奖回访**为"到期提醒(演示)" toast:正式版用一次性订阅消息(用户主动授权),避免报告预警的"第 8 天断崖"。
4. **自证**:买没买凭自觉;可选订单截图上传(不强制)排 P1。
5. **变现位未接**:按报告——激励视频放揭晓页(解锁全场分布/毒舌理由)与档案页,不做开屏;接流量主前先过起量线(K≥0.3)。
6. 揭晓动画(幕布擦除)已有占位类 `.curdiv`,开奖舞台的专属入场动画可在视觉打磨轮加强。
7. 「快进 7 天(演示)」按钮在提审版需移除,避免审核误判。
